# 行序 · 前端页面原型

账号注册、登录以及 CSV 上传检查和预览已接入后端，工作台的文件、任务列表仍为静态示例。

## 预览

在项目根目录运行：

```powershell
.\.venv\Scripts\python.exe -m http.server 8765 --bind 127.0.0.1 --directory frontend
```

打开 http://127.0.0.1:8765 。这只是提供页面文件的静态服务器。

登录／注册页面：http://127.0.0.1:8765/auth.html 。工作台右上角也有入口。

## 注册使用

在另一个终端启动后端：

```powershell
.\.venv\Scripts\python.exe -m uvicorn backend.app.main:app --reload --port 8000
```

在账号页面切换到注册，输入账号、密码和确认密码后提交。注册请求发送到 `POST http://127.0.0.1:8000/api/auth/register`，成功会写入 MySQL，并清空密码、保留规范化账号、切回登录表单。
提交期间禁用按钮和表单切换，失败显示后端错误或连接提示；请求超时不自动重试，结果可能尚未确认。
注册成功后切换到登录表单。登录按钮请求 `POST /api/auth/login`，成功后将访问令牌、续期凭据和到期元数据作为一个记录保存到当前标签页的 `sessionStorage`，不保存密码，再进入工作台。

工作台通过 `GET /api/auth/me` 验证身份，使用 `Authorization: Bearer <令牌>`。首次身份确认前隐藏工作台；网络失败、请求超时或服务暂不可用时保留令牌，按 2、5、10、30 秒退避重试，之后最多每 30 秒一次。离线时等待网络恢复，不反复发送请求。

“立即重试”会重新发送登录状态查询，不刷新页面；已打开工作台的备注、搜索条件等输入保留。网络恢复、页面重新可见时也会检查身份；成功后清除提示。后端明确返回 `401` 时才清除失效令牌并提示重新登录，不强制跳转清空页面。

页面按后端有效期提前约六分之一、最多 5 分钟申请续期：默认 30 分钟令牌在约第 25 分钟调用 `/api/auth/refresh`，成功后重新安排下一次，无需点击或输入。返回页面和网络恢复时也会检查；没有必要时不会发送续期请求。

访问令牌过期后，只要续期凭据和会话仍有效，就能先恢复再查身份。恢复窗口默认从最后成功续期计算 12 小时。失败时保留页面与凭据，并以同一持久化请求编号重试；后端已处理、响应丢失时也不会重复轮换。

点击退出清除本标签页凭据、停止续期，并调用 `/api/auth/logout` 撤销后端会话。网络不可达时会明确提示服务器退出暂未确认。迟到的旧请求不会恢复退出前的身份。任务和文件列表仍为静态示例，真实上传结果只展示在上传弹窗中。

自动重试用于只读身份查询及带请求编号、可恢复的续期操作，不自动重发注册、登录或上传等其他写入请求。首次升级到带会话的令牌后需重新登录一次，旧 JWT 没有会话编号。

账号页面中的“预览工作台”使用 `index.html?preview=1`，只显示静态示例，不请求受保护的用户接口或提交文件；登录后从正常入口上传。

后端地址在 `auth.html` 和 `index.html` 的 `api-base-url` meta 中配置；允许访问的前端来源由后端 `CORS_ALLOWED_ORIGINS` 配置，默认允许 `127.0.0.1:8765` 和 `localhost:8765`。
请通过上面的 HTTP 静态服务器访问页面；修改代码后可按 `Ctrl+F5` 强制刷新。

## 上传与预览

登录后点击“上传文件”，选择或拖入一个 CSV，再点击“上传并预览”。提交前复用 `AuthSession.currentUser()` 检查身份及必要续期，以当前访问令牌发送 `POST /api/files`。文件通过 `FormData` 的 `file` 字段提交，不手动设置 Content-Type，由浏览器生成 multipart 边界。

请求期间禁用重复提交和文件切换，显示正在检查，不模拟百分比。后端返回 `422` 或 `413` 时显示错误原因并保留所选文件；网络失败或 120 秒超时后需手动重试，不自动重复上传。关闭弹窗取消当前等待，旧响应不会重新显示结果。

检查成功后显示后端的 `preview_rows`，使用“第1列、第2列……”作为展示标题，首条记录也作为普通记录展示。文件名和字段使用 DOM 的 textContent 展示，保留前导零与换行，不把上传内容作为 HTML。`preview_truncated` 为 true 时提示预览上限；空预览也会明确提示。

当前 `persisted=false`，文件尚未正式保存，预览不会新增任务、文件列表记录、报告或确认表头。刷新页面后所选文件和预览不保留。

## 当前范围

- 任务概览、任务表格、数据文件及规则页面。
- 登录／注册表单切换、密码可见性切换；账号按钮发送真实请求，显示错误和成功提示。
- 登录页的「预览工作台」仅用于页面导航，不代表登录成功。
- 固定示例数据，展示排队、处理中、成功及失败状态。
- 页面切换、示例筛选、搜索、详情侧栏和上传表单。
- 选择文件后展示文件名和大小，点击上传后由后端执行基础检查，并返回前 5 条原始记录预览。
- 任务重试、下载、导出、列表刷新仍预留按钮，待接入后端。

文件基础检查和 CSV 语法解析在后端执行；工作台没有逐行业务校验、金额计算、后台任务、队列模拟、自动进度变化或报告生成。账号密码不写入浏览器存储，当前标签页只保存登录凭据和到期元数据。

## 文件职责

| 文件 | 职责 |
| --- | --- |
| index.html | 页面结构和弹窗 |
| styles.css | 页面样式和响应式布局 |
| demo-data.js | 纯静态展示数据 |
| app.js | 渲染、页面切换、示例筛选和弹窗交互 |
| file-upload.js | 单文件选择/拖拽、登录后上传、错误提示及原始记录预览 |
| auth.html | 登录／注册页面结构 |
| auth.css | 独立的账号页面样式 |
| auth.js | 表单及密码可见性切换、注册/登录请求和结果提示 |
| auth-session.js | 当前标签页凭据存取、到期调度、可恢复续期、Bearer 请求和退出 |
| workbench-auth.js | 工作台身份确认、过期处理、退出和静态预览入口 |

后续实现真实工作台接口，并在后端按当前用户过滤文件、任务等业务数据。

## 自动化检查

在项目根目录执行：

```powershell
node --test frontend/tests/auth-session.test.cjs frontend/tests/file-upload.test.cjs
```

这些检查使用模拟 DOM、时钟和响应，不会在页面运行中制造故障。
