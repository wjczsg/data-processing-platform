# 行序 · 前端页面原型

当前只搭建页面布局和展示交互，后端业务尚未实现。

## 预览

在项目根目录运行：

```powershell
.\.venv\Scripts\python.exe -m http.server 8765 --bind 127.0.0.1 --directory frontend
```

打开 http://127.0.0.1:8765 。这只是提供页面文件的静态服务器。

登录／注册页面：http://127.0.0.1:8765/auth.html 。工作台右上角也有入口。

## 当前范围

- 任务概览、任务表格、数据文件及规则页面。
- 登录／注册表单切换、密码可见性切换；提交按钮待接入后端。
- 登录页的「预览工作台」仅用于页面导航，不代表登录成功。
- 固定示例数据，展示排队、处理中、成功及失败状态。
- 页面切换、示例筛选、搜索、详情侧栏和上传表单。
- 选择文件后仅显示文件名和大小，不读取内容。
- 提交、重试、下载、导出、刷新均预留按钮，待接入后端。

没有文件解析、数据校验、金额计算、任务执行、队列模拟、自动进度变化、报告生成、网络 API 调用或浏览器持久化。

## 文件职责

| 文件 | 职责 |
| --- | --- |
| index.html | 页面结构和弹窗 |
| styles.css | 页面样式和响应式布局 |
| demo-data.js | 纯静态展示数据 |
| app.js | 渲染、页面切换、示例筛选和弹窗交互 |
| auth.html | 登录／注册页面结构 |
| auth.css | 独立的账号页面样式 |
| auth.js | 表单及密码可见性切换，不执行认证或保存凭证 |

下一步先确认页面布局，再逐个设计后端接口并接入真实数据。
